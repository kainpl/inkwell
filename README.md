# Inkwell

Десктопний редактор Markdown у дусі **Typora** — без панелі прев'ю. Ти просто
пишеш, а маркери розмітки (`#`, `**`, `` ` `` тощо) ховаються на льоту, тож
текст виглядає як готовий документ. Наводиш курсор на рядок — маркери цього
рядка знову з'являються (приглушені), щоб їх можна було редагувати.

У живому режимі Inkwell відображає таблиці, зображення, чекбокси, блоки коду,
формули KaTeX та діаграми Mermaid. Щоб побачити весь Markdown із номерами
рядків, натисни **Вихідний код** (Source) у верхній панелі. Повторне натискання повертає
живий документ. Курсор, виділення та історія Undo спільні для обох режимів.

## Стек

Tauri 2 + Vite · React 18 + TypeScript · TailwindCSS · CodeMirror 6 ·
Zustand.

## Швидкий старт

```bash
npm install
npm run dev      # запуск з HMR
```

Для розробки потрібні Node.js 22.13+ або 24+, Rust stable та системні залежності Tauri. На Windows це MSVC Build Tools із компонентами C++ і Microsoft Edge WebView2. [Вимоги Tauri для кожної ОС](https://v2.tauri.app/start/prerequisites/)

Збірка дистрибутива:

```bash
npm run build:win    # Windows: NSIS
# На macOS: npm run build:mac. На Linux: npm run build:linux.
```

Інсталятор для поточної платформи з’являється в `src-tauri/target/release/bundle/`.

## Налаштування

Відкрий **Файл → Налаштування** або натисни **Ctrl+,** (**⌘+,** на macOS). Можна змінити мову інтерфейсу, палітру, типографіку, режими письма, гарячі клавіші й розширення Markdown. Ціль у словах прив’язана до поточного файла.

Для перевірки правопису ввімкни український чи англійський словник або обидва. Клік правою кнопкою по підкресленому слову відкриває виправлення й додавання до особистого словника. Обидва словники працюють офлайн.

Автозбереження початково вимкнене. Якщо його ввімкнути, зміни записуються після короткої паузи. Новий документ спочатку потрібно зберегти вручну.

## Стандартні гарячі клавіші

| Дія | Клавіші |
| --- | --- |
| Новий файл | `Ctrl/⌘ N` |
| Відкрити файл | `Ctrl/⌘ O` |
| Відкрити теку | `Ctrl/⌘ Shift O` |
| Зберегти | `Ctrl/⌘ S` |
| Зберегти як | `Ctrl/⌘ Shift S` |
| Сайдбар | `Ctrl/⌘ \` |
| Аутлайн | `Ctrl/⌘ /` |
| Focus mode | `Ctrl/⌘ Shift F` |

## Що всередині

Коротко: рушій «живого прев'ю» — це CodeMirror-розширення
`src/renderer/src/components/Editor/livePreview.ts`. Воно ходить по дереву
розбору Markdown і вирішує, які маркери сховати, а які показати (залежно від
того, де курсор). Деталі — у `docs/ARCHITECTURE.md`.
