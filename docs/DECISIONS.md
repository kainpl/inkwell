# Технічні рішення (ADR)

Короткі записи «чому саме так», щоб не повертатися до тих самих суперечок.

## 1. Редактор: CodeMirror 6, а не ProseMirror/TipTap/Milkdown
**Рішення.** Рушій редагування — CodeMirror 6 із декораціями, що ховають
розмітку.

**Чому.** Для Markdown-редактора джерело істини має лишатися **текстом
Markdown**. CodeMirror редагує саме текст, а «документний» вигляд накладає
зверху декораціями. Звідси: ідеальний round-trip (відкрив→зберіг — байти ті
самі), рідна поведінка «маркери проявляються на активному рядку» (фірмова фішка
Typora), повний контроль над кареткою й виділенням.

**Альтернатива.** ProseMirror (і обгортки TipTap/Milkdown) — справжній WYSIWYG
із власною деревовидною моделлю. Потужно, але кожен імпорт/експорт у Markdown —
це серіалізація, де легко втратити нюанси сирого тексту (порядок атрибутів,
«неканонічна» розмітка, HTML-вставки). Для застосунку, де користувач свідомо
працює з .md-файлами, це мінус. Залишаємо як можливий pivot, якщо колись
знадобиться 100% WYSIWYG без видимого тексту взагалі.

## 2. Десктопна оболонка Tauri 2

Tauri використовує системний WebView, що зменшує склад дистрибутива. Vite обслуговує
React і CodeMirror. На Windows для запуску потрібен WebView2.

## 3. Стан: Zustand
**Чому.** Легкий, без бойлерплейту Redux, читання селекторами + імперативний
`getState()` для обробників меню/IPC. Для одного документа й кількох UI-прапорців
цього з головою; за потреби легко розрости.

## 4. Стилі: Tailwind для «хрому» + семантичний CSS для контенту
**Рішення.** UI-оболонку (панелі, кнопки, бари) верстаємо Tailwind-утилітами;
сам **контент редактора** стилюємо класами `.ink-*`/`.cm-*` у `index.css`.

**Чому.** Контент-стилі мусять застосовуватися до DOM, який генерує CodeMirror
(а не React), тож Tailwind-класи туди не повісиш — простіше тримати їх як
звичайний CSS. А кольори обох світів ідуть через однакові CSS-змінні теми, тож
світло/темрява лишаються синхронними.

## 5. Темізація через CSS-змінні
**Чому.** Перемикання теми не повинно чіпати ні React-дерево, ні рушій
декорацій. Усе зводиться до набору `--paper/--ink/--accent/...` у `:root` та
`.dark`. Нова тема = новий блок змінних.

## 6. Доступ до системи

Нативні діалоги надають доступ до вибраного файлу або теки. Типізований адаптер
`window.api` використовує файловий плагін Tauri. Локальні зображення завантажуються
через окремий протокол з перевіркою типу файлу.
