# Можливості: мапа Typora → Inkwell

Зведення того, що вміє Typora, і де воно в Inkwell. Статуси: ✅ є в каркасі ·
🟡 частково / заготовка · ⬜ заплановано (див. `ROADMAP.md`).

## Ядро: seamless live preview
| Можливість | Статус | Нотатки |
| --- | --- | --- |
| Живий рендер без панелі прев'ю | 🟡 | Рушій `livePreview.ts` працює для заголовків, **жирного**, *курсиву*, `~~закреслення~~`, `inline code`, посилань |
| Маркери проявляються на активному рядку | ✅ | `activeLines()` + `Decoration.replace`/`ink-mark` |
| Заголовки H1–H6 з реальними розмірами | ✅ | класи `ink-h1..h6` |
| Перенос рядків, центрована «сторінка» | ✅ | `EditorView.lineWrapping` + `.cm-content` max-width |

## Markdown (GFM)
| Можливість | Статус | Нотатки |
| --- | --- | --- |
| Заголовки, списки, цитати | 🟡 | заголовки готові; списки/цитати — базово через CM, потребують стилів |
| Жирний / курсив / закреслення / код | ✅ | інлайнові декорації |
| Посилання | 🟡 | стиль є; ⬜ клік-перехід, приховування URL у віджет |
| Таблиці (візуальне редагування) | ⬜ | потрібен WidgetType + редактор клітинок |
| Code fence з підсвіткою 100+ мов | 🟡 | мови підвантажуються (`language-data`); ⬜ фон/рамка блоку |
| Task list `- [ ]` з кліком | ⬜ | чекбокс-віджет із toggle |
| Зображення інлайн | ⬜ | WidgetType, що рендерить `![]()` коли рядок неактивний |
| Математика (KaTeX) `$...$`, `$$...$$` | ⬜ | окреме розширення + KaTeX |
| Діаграми (Mermaid) | ⬜ | блок-віджет із рендером Mermaid |
| Виноски, визначення, emoji | ⬜ | |

## Робота з файлами
| Можливість | Статус | Нотатки |
| --- | --- | --- |
| Дерево файлів (file tree) | ✅ | `FileTree.tsx`, лінива підвантаж тек |
| Відкрити файл / теку | ✅ | через діалоги main-процесу |
| Зберегти / Зберегти як | ✅ | round-trip працює |
| Список статей (article list) | ⬜ | окрема панель останніх/усіх md |
| Автозбереження | ✅ | Для названих файлів після паузи у введенні |
| Попередження про незбережене | ⬜ | guard перед відкриттям/закриттям |

## Навігація та режими письма
| Можливість | Статус | Нотатки |
| --- | --- | --- |
| Панель аутлайну (з заголовків) | ✅ | `OutlinePanel.tsx`, клік → перехід |
| Focus mode (підсвітити лише поточний рядок) | ✅ | CSS `.ink-focus` + `highlightActiveLine` |
| Typewriter mode (активний рядок по центру) | ✅ | Редактор центрує рядок під час введення |
| Зміст (TOC) `[toc]` | ⬜ | генерація зі списку заголовків |
| Внутрішні посилання на заголовки | ⬜ | |

## Експорт та оформлення
| Можливість | Статус | Нотатки |
| --- | --- | --- |
| Світла / темна тема | ✅ | CSS-змінні + перемикач |
| Кастомні теми через CSS | 🟡 | механізм є (`[data-theme]`); ⬜ завантаження зовнішніх .css |
| Експорт у HTML | ⬜ | рендер md → HTML (remark/markdown-it) |
| Експорт у PDF | ⬜ | через `webContents.printToPDF` |
| Експорт у Word/інше | ⬜ | напр. pandoc-інтеграція |
| Завантаження/вставка зображень | ⬜ | drag&drop, paste, відносні шляхи |

## Поза рамками Typora (ідеї)
- Команда-палітра (`Ctrl/⌘ K`).
- Граф зв'язків між нотатками.
- Git-статус прямо в дереві файлів.
