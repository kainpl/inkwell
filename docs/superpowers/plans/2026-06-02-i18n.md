# UI internationalization (EN / UK / RU) — design & plan

**Goal:** Translate the Inkwell UI into English (default), Ukrainian and Russian,
switchable at runtime, covering the native menu and the renderer UI.

**Branch:** `feat/i18n` · **Mechanism:** hand-rolled (no dependency) · **Rollout:** phased.

## Architecture

- `src/shared/i18n/` — dictionaries usable by **both** main (menu) and renderer:
  - `index.ts`: `Locale = 'en' | 'uk' | 'ru'`, `LOCALES`, `LOCALE_NAMES`,
    `DEFAULT_LOCALE`, `translate(locale, key, vars?)` (flat dotted keys, `{var}`
    interpolation, falls back to `en` then the key).
  - `en.ts` / `uk.ts` / `ru.ts`: flat `Record<string,string>` of `key → text`.
- **Renderer** (`lib/i18n.ts`): `useT()` hook selects `locale` from the store and
  returns a bound `t(key, vars?)` so components re-render on language change; a
  non-reactive `t()` for non-component code reads `useAppStore.getState().locale`.
- **Settings/store**: `locale` (persisted, default `en`) + setter + `settingsSync`
  pushes it to main (`window.api.setLocale`) so the menu rebuilds.
- **Main**: `buildMenu(win, locale)` uses `translate`; an IPC `setLocale` rebuilds
  the menu (main keeps the current locale; starts at `en`, then the renderer's
  settings sync sets the real one).
- **Preferences ▸ General**: a Language selector (English / Українська / Русский).

## Phases (each a commit; UK + RU translations written as we go)

- **P1 — Infra + native menu + core chrome.** shared/i18n, settings/store/sync,
  main menu rebuild + `setLocale` IPC + preload, Preferences language selector,
  and translate: the **native menu** (~100 strings), TitleBar tooltips, StatusBar,
  Sidebar tabs, TabBar, StartScreen.
- **P2 — Modals, palette, Preferences.** Command palette titles, Preferences pane
  labels, and the main modals (QuickOpen, GlobalSearch, RecentPicker, SourceControl,
  DriveConnect, NoteGraph, PageSetup, Pandoc/Spell download, Confirm/Prompt…),
  toolbar tooltips.
- **P3 — Long tail.** Remaining modals, FileTree context menu, inline strings,
  error/empty-state messages. Audit for missed strings.

## Verification

Pure `translate` + key-coverage unit tests (every key present in all locales).
Live probe: switch locale → menu + chrome re-render in UK/RU (screenshot).
